# 아트 바이블 — 「기억의 장경각」 (2026-08-21, 오너 확정)

오너 판정: G0 슬라이스 품질 합격, 단 흰 패널 실험실 문법은 포털 표절로 읽힐 위험 → **오리지널 아이덴티티로 전환**. FP 시점·품질 기준·클린한 가독성은 유지.
컨셉 한 줄: **해인사 장경판전(팔만대장경 보관소) × 시간 기술.** 기억 보관소라는 픽션의 실물이 이미 한국에 있다 — 8만 장의 기록이 서가를 채운 어두운 목조 전각. 레퍼런스: `captures/refs/janggyeonggak-grid.jpeg` (Read로 볼 것).

## 시각 언어 (포털 문법 → 장경각 문법 치환표)
| 포털(폐기) | 장경각(채택) |
|---|---|
| 흰 사각 패널 벽 | **경판 서가 벽**: 바닥~천장 다크 우드 선반에 검은 기억함(경판 비례의 목함) 수백 개 인스턴싱. 소수(~5%)가 시안 빛샘 = 재생 가능한 기억 |
| 블랙 그리드 천장 | 목재 서까래·보 리듬 + 어두운 회벽 |
| 형광 스트립 조명 | **살창 줄무늬 빛**: 격자 살창(상부)에서 따뜻한 사광이 들어와 바닥에 밴드 패턴. 이것이 시그니처 룩 — 모든 방의 주광 |
| 회색 바닥 타일 | 짙은 전돌 + 목재 마루 혼합, 살창 빛 밴드가 떨어지는 캔버스 |
| 슬라이드 도어 | **장지문**(목재 프레임+한지, 뒤에서 발광) — 열릴 때 옆으로 미끄러짐, 닫히면 한지 투과광 |
| 챔버 번호 사인 | **한지 현판**: 세로쓰기 한글 방 이름 + 로마자 소자 + **붉은 낙관**(방 번호가 도장 안에) |
| 관측창 | 살창 너머 희미한 안쪽 공간 (비어 있는 열람실) |
| 흰 케이스 큐브 | 흑칠 목함 + 시안 코어 빛샘 (황동 모서리) |
| 발판/스위치 | 발판=바닥 황동 원판+시안 링, 스위치=황동 손잡이 기둥 |

- 낙관 레드: #b83b2e (도장·강조에만 — 제3의 액센트, 아껴 쓸 것)
- 시간 기술: 시안(에코·기억 빛샘·루트 라인)·앰버(현재 동선·출구 온광) 유지

## 연출 모티프
- **⏎ 기록 끝내기 = 봉인 낙관**: 화면 중앙 하단에 붉은 도장이 쿵 찍히는 0.4s 플래시(회전 살짝+스케일 다운), reduced-motion은 정적 표시. HUD 칩도 도장 모양.
- 기록 시작 = 서가의 기억함 하나가 열리며 시안 빛; 성공 = 그 함이 닫히고 봉인.
- 에코: 시안 홀로그램 유지(알파+프레넬). 어두운 목조 배경에서 극대비 — 흰 방보다 오히려 유리.
- 먼지 모트는 살창 빛 밴드 안에서만.
- 자막/HUD: 한지톤 반투명 패널+먹색 텍스트, 낙관 레드 포인트.

## 지켜야 할 것
- FP 가독성: 어두운 방이지만 C1.5b 원칙(암부 크러시 % 측정) 적용 — 서가 디테일이 읽혀야 함. 살창 빛+한지 투과광+황동 온광 3원으로 밝기 확보.
- 성능: 기억함 인스턴싱(수백 개), 전환 시점 할당 금지(6회 교훈), depth pre-pass 함정(반투명 2사이트 확인됨) 회피.
- 결정론: 렌더 온리. 심 불변.
- 모든 프로시저럴 — 런타임 래스터 에셋 0 유지.
