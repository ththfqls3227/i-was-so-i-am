# I WAS, SO I AM — Four-Room Journey Evidence

This repository contains the complete protected four-room browser journey from title to farewell ending.

## What is implemented

- Fixed 30 Hz pure TypeScript simulation with integer/fixed-point coordinates.
- Versioned input-intent tape, checksum validation, canonical reset, exactly one past echo and one present self.
- `Crossing`: the dedicated tutorial teaches one complete record-then-cooperate loop while the recorded past sustains the present's bridge.
- `Trace Weight`: the second room opens the present's route, then reunites both selves at a shared weight.
- `Handoff`: the past stages a memory core and the present receives and delivers it.
- `Last Hold`: the echo stays behind holding the final mechanism while the present exits.
- Title, four-room transitions, pause/settings, Korean/English copy, responsive touch controls, local progress, and ending/credits.
- Immediate rerecord, neutral post-tape transition, 250 ms hold grace, and recoverable invalid-tape handling.
- Babylon.js 9.21 render-only adapter with a live procedural 3D vault, chasm, mechanisms, articulated human, and cyan echo. No raster runtime art, remote assets, login, analytics, backend, or engine-authoritative physics.

## Automated gate

Run:

```bash
npm run validate
npm run test:e2e
npm run test:visual-diff
npm run test:performance # with the local Vite server on port 4173
```

The replay corpus contains 100 seeded tapes and compares every authoritative tick twice. Playwright runs the same golden checksum sequences through Chromium, Firefox, and WebKit at declared 30/60/144 render-cadence inputs, and the Chromium full journey records the past before controlling the present in every room. The final gameplay capture scored 90/100 against the approved thumbnail-style reference. The pixel comparison remains reproducible secondary evidence, not a similarity gate between concept art and interactive geometry. Retired concept references and the zero-runtime-raster contract are documented in [asset-provenance.md](asset-provenance.md).
