# Phase F 스펙 — 「기억 보관소」: 규모·스토리·클린 챔버 (2026-08-20, 오너 피드백 라운드)

오너 결정: ①아트를 **클린 시험 챔버**(포털 스타일)로 피벗 ②튜토리얼 **마이크로 챔버 3개** 추가, 개념 스텝 바이 스텝 ③Handoff **단순화 재설계** ④한국어 카피 전면 재작성("시간을 접는다" 등 어색한 표현 제거) ⑤**규모 확장** — 짧은 데모가 아니라 스토리 있고 단계별로 깨나가는 게임.
레퍼런스 학습(2026-08-20): 포털 챔버 사인(큰 번호+진행바+메커니즘 픽토그램), 흰 패널+다크 존 대비, 바닥 시안 점선 루트 / 크로노트론(한 방=한 트릭, 개수로 스케일, 레벨 셀렉트).
불변: 결정론 코어 렌더-온리, 런타임 래스터 0, 브라우저 즉시 플레이, `gate:submission` 그린 유지, 커밋 트레일러 규칙.

## F1. 세계관·스토리 (텍스트 몇 줄로 구현되는 아크)
- 무대: **기억 보관소** — 떠난 사람의 하루하루가 챔버로 보관된 시설. 플레이어는 위층(최근 기억)에서 아래층(오래된/깊은 기억)으로 내려간다.
- 딜리버리: ①챔버 입장 시 시설 자막 1~2줄(사무적 톤 → 내려갈수록 인간적 톤으로 변화, 스킵 가능) ②구역 전환 인터타이틀(구역명+한 문장) ③엔딩(기존 이별 비트 유지·강화).
- 감정선: 초반 "보관 절차 안내"처럼 굴던 시설 문구가, 후반 "이 기록을 남긴 것은 당신입니다" 계열로 뒤집히며 제목(I WAS, SO I AM)을 회수.
- 카피 원칙: 대구 구조 반복 금지, 번역투 금지, 실제 게이머 언어. 시적 표현은 구역 전환·엔딩에만.

## F2. 챔버 로스터 (서장 3 + 4구역 = 총 10 플레이 챔버, 증분 설계)
각 챔버 = 새 아이디어 정확히 1개. 뒤 구역은 앞 구역 개념의 조합. 06~08은 시간 부족 시 절삭 가능한 증분(각각 골든+테스트와 함께 커밋).

| # | 구역 | 이름(가) | 가르치는 것 / 퍼즐 |
|---|---|---|---|
| 00 | 서장 | 깨어남 | 이동+발판(신규 plate)을 밟으면 문이 열림. 기록/재생 루프를 부담 없이 통과(협동 불필요) |
| 01 | 서장 | 두 번째 나 | 에코가 발판을 밟고 있어야 문이 열림 — 협동 필수의 최소형 |
| 02 | 서장 | 기록 끝내기 | 현 Crossing 개조: 윈치 잡기 + ⏎ 기록 끝내기 학습 |
| 03 | 1구역 | 몸이 아니라 손 | **blocked-input 트릭**: 기록 중 닫힌 문에 막힌 채 전진+잡기 유지 → 재생 때 (내가 열어준) 문을 뚫고 지나가 스위치를 잡는다 |
| 04 | 2구역 | 함께 드는 무게 | 현 TraceWeight 유지(사인·동선 라인으로 안내 강화) |
| 05 | 3구역 | 열어주는 손 | **Handoff v3 단순화**: 과거가 스위치를 붙들어 게이트를 여는 동안, 현재가 받침대의 상자를 들고 통과해 수구에 넣는다. 릴레이·교차점·리다이렉트 규칙 전부 제거. 코어: 캐리어 픽업의 stagedByPast 전제 제거(픽업 가능 액터를 챔버 데이터로 지정) |
| 06 | 1구역 | 교차 | hold 2개: 과거가 A스위치를 잡는 동안 현재가 B스위치를 잡아 서로의 문을 연다 (절삭 후보 1) |
| 07 | 2구역 | 무게의 릴레이 | 과거가 블록을 절반 밀고 홀드로 이동, 현재가 나머지 절반을 이어 민다 (절삭 후보 2) |
| 08 | 3구역 | 되돌아오는 길 | pushDirection left + 왕복 동선 응용 (절삭 후보 3) |
| 09 | 4구역 | 마지막 붙듦 | 현 LastHold 유지 — 피날레 |

- 신규 코어 메커니즘 **1개만**: `plate`(밟고 있는 동안 활성, hold의 무입력 변형; requiredActor 지원, door.gatedBy에 'plate' 추가). 그 외 조합은 기존 메커니즘 재사용.
- 방 크기: 구역이 진행될수록 world 치수·동선 확대(넓어지는 느낌). 후반 챔버 tapeDurationTicks 상한을 20s(600틱)까지 허용 — 관련 유닛테스트의 14s 제약을 챔버별 상한으로 완화.
- 진행 저장: localStorage 진행도 확장(클리어한 챔버 목록). **챔버 선택 화면**: 타이틀에서 구역별 그리드, 클리어한 챔버+다음 챔버만 잠금 해제. `switchChamber` 재사용.

## F3. 아트 피벗 — 클린 시험 챔버
- 팔레트: 오프화이트 패널(#e8e6e0 계열, 미세 그리드 심), 다크 메커니즘 존(#2a2d33), 액센트 시안(과거)·앰버(현재) 유지, 경고 스트라이프 최소 사용.
- 벽: 대형 사각 패널 모듈(프로시저럴 — 패널 심+미세 베벨 노멀), 다크 존은 메커니즘 주변에만. 유리 관측창 1개/방(빈 관측실 — 스토리 장치).
- 조명: 밝고 균일한 주광(천장 스트립 발광) + 소프트 섀도 + 은은한 AO. 어둡고 무디한 볼트 룩 폐기. 포스트: 노출/대비 재조정, 비네트 약화.
- **사인 시스템**(핵심): 입구 사인 패널 = 큰 챔버 번호 + 진행바(01/10) + 이 방 메커니즘 픽토그램 타일(기록·에코·발판·스위치·상자·무게추 아이콘 세트, DynamicTexture 벡터풍). 
- **바닥 루트 라인**: 앰버 실선=현재 동선 제안, 시안 점선=과거(기록) 동선 제안 — 방마다 저작. 골드 타겟 링과 일관.
- 메커니즘 드레싱: 클린 산업 디자인(발판=원형 압력판+링 발광, 스위치=기둥형 레버, 게이트=수직 슬라이드 도어, 상자=흰 큐브+시안 코어 = 컴패니언 큐브 문법).
- 캐릭터: 현행 유지하되 새 조명에 재질 재조정. 에코 additive 품질 유지.
- 썸네일: 새 룩 확정 후 인게임 장면으로 재촬영(1920×1080), reference-v1은 폐기 후보.

## F4. UI 간소화 + 카피 전면 재작성
- 1차 안내=환경(사인·바닥 라인·발광), 2차=튜토리얼 카드. 카드는 **제목 1줄+체크리스트만**으로 축소(본문 설명은 처음 등장하는 개념에만).
- 용어 교체: 「시간 접기」→ **「기록 끝내기 ⏎」** (본문: "지금 자세 그대로 기록을 마칩니다"). "메아리 남은 시간"→"기록 시간" / "재생 시간". 전 카피 자연어 검수: 번역투·한자어 남발·대구 반복 제거. 영문 카피 동반 갱신.
- 패스 표기: "1회차 기록/2회차 협동" 유지하되 배지·배너 문구 자연화.
- 실패 카피: 사실+다음 행동 1문장. failureCopy 전면 재검토.
