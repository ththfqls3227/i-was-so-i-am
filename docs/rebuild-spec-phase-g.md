# Phase G 스펙 — 1인칭 재구축 「I WAS, SO I AM」 (2026-08-21, 오너 결정)

오너 결정: 기존 쿼터뷰 파운데이션 전면 폐기. **아이디어만 유지**하고 1인칭(진짜 포털 시점)으로 백지 재구축. 마감 8/26.
유지되는 것: 코어 아이디어(기록→메아리 협동→기록 끝내기⏎→이별 피날레), 스토리·카피 보이스(w3-voice-draft), 시설 세계관(기억 보관소), 챔버 로스터 개념(서장→구역별 진행), 오디오 엔진, git/게이트/문서 체계.
폐기되는 것: 2D 평면 월드 모델, 쿼터뷰 렌더러/카메라, 기존 챔버 데이터·골든, 기존 UI 셸.

## G-A. 아키텍처 (결정론 규율은 그대로, 월드는 3D)
- **새 3D 결정론 코어** (`src/sim/`): 30Hz 고정 틱 유지. InputFrame = 이동 벡터(카메라 기준 WASD, 8방향+정지 아님 — 아날로그 아닌 불리언 4키) + **양자화 yaw**(1/4096 회전 단위, 마우스는 렌더에서 자유, 심은 틱마다 양자화 값 소비) + pitch는 심 비관여(상호작용 레이캐스트는 yaw+고정 눈높이로 판정) + jump/act/fold/rerecord 버튼. 결정론 원칙: Math.hypot 금지, Date/random 금지, 체크섬·테이프 버전·리플레이 코퍼스 패턴 이식.
- **물리**: 캡슐 vs AABB 브러시(방=AABB 목록). 중력+점프(고정 점프 커브), 계단 없음(램프·리프트로), 슬라이딩 충돌(축분리+pushout). 이동감 튜닝 목표: 걷기 4.5m/s, 점프 1.1m, 에어컨트롤 소량.
- **기록/재생**: 동일 패턴 — 1회차 몸으로 기록, ⏎ 기록 끝내기(자세 유지 꼬리: 이동+yaw+act 유지, 엣지 스트립 — 기존 교훈 이식), 2회차 협동, 리플레이 윈도우 고정, 실패 코드 체계 이식.
- **메아리**: 풀바디 반투명 시안 고스트(알파+프레넬 — W2 교훈), 테이프 재생으로 걷고 점프하고 잡는 모습이 **보인다**. 이것이 이 게임의 핵심 샷.
- **상호작용**: 시선 레이캐스트(사거리 2.2m) + E 홀드(스위치), 발판(서기), 큐브 들기(E 토글, 카메라 앞 부양 — 포털 문법), 슬라이드 도어, 출구 게이트. 메커니즘 의미론(hold/plate/door/carrier/exitGate/latch)은 기존 설계 이식하되 3D로.
- **렌더** (`src/fp/`): Babylon 유지. FP 카메라(렌더 보간, 심 위치 lerp), 클린 패널 재질(W2에서 검증된 프로시저럴 패널+심+노멀), 천장 라이트 스트립, 다크 메커니즘 존, 챔버 사인(W2 시스템 이식 — FP에서 벽 사인은 더 강력), 관측창, 안개 미량. 손/총 없음 — 크로스헤어+미니멀 HUD.
- **HUD**: 크로스헤어(상호작용 가능 시 변화), 하단 테이프 바, 중앙 하단 프롬프트(E/⏎/R), 자막 라인. 튜토리얼 카드 폐기 — **다이제틱 사인+자막이 1차, HUD 프롬프트가 2차** (기존 카드형 UI는 FP에 안 맞음). 정직성 원칙 유지: ⏎ 프롬프트는 성공 가능할 때만.
- **코드 배치**: 기존 src/core·src/game·src/main.ts는 당분간 보존(빌드만 유지), 새 게임은 src/sim + src/world + src/fp + 새 엔트리. 파리티 도달 시(G2) 구코드 제거. 오디오 src/audio는 어댑터로 재사용.

## G-B. 마일스톤
- **G0 수직 슬라이스 (오늘, 최우선)**: 방 1개(깨어남 등가: 스폰→발판→문→출구 복도), FP 컨트롤러 풀셋(WASD+마우스+점프+E+⏎+R+Esc), 기록→재생 에코 가시화, 클린 패널 룩 v1, 미니멀 HUD, 브라우저 즉시 플레이. **오너 체크포인트** — 느낌 확인 후 진행.
- **G1 시스템 완성**: 큐브 들기, 전 메커니즘, 실패/재기록 루프, 자막·사인, 챔버 전환, 진행 저장, 오디오 연결(발소리 추가).
- **G2 챔버 이식**: 서장 3개+구역 4개(기존 퍼즐 설계를 3D 공간으로 재해석 — 수직성 활용: 점프·리프트·2층 구조로 "넓다" 체감), 스토리 자막, 챔버 셀렉트.
- **G3 폴리시**: 라이팅·이펙트(기록 시작/끝 연출, 에코 등장), 카피 확정(w3-voice-draft), 밸런스, 성능(60fps).
- **G4 게이트·제출**: 새 코어 유닛+코퍼스, sim 레벨 저니, e2e 스모크, dist 게이트 재배선, 배포, 썸네일(FP 인게임 샷 — 메아리와 마주 선 장면), 데모 영상.

## G0 상세 (구현 에이전트 지시)
- 방 사양: 12×4×18m 패널 룸. 스폰 → 6m 앞 원형 발판(시안 링) → 발판이 슬라이드 도어 개방(latchOnOpen) → 도어 뒤 6m 복도 → 출구 빛. 기록: 발판까지 걸어가 서기 → ⏎ → 재생: 메아리가 같은 길을 걷는 걸 **지나치며 보고** 문으로. (협동 불필요 — 00 설계 이식)
- 룩 v1 기준: 오프화이트 패널(1.2m 모듈, 리세스 심), 다크 존(발판 주변 바닥+도어 프레임), 천장 스트립 2열, 소프트 섀도 1키, 시안 발판 발광, 앰버 출구 빛. 안개 0.008. 블룸 보수적. **화면이 "게임 스크린샷"으로 보여야 함 — 모델뷰어 금지.**
- 느낌 기준: 마우스 감도 자연(0.0022 rad/px 기본+설정), 60fps, 이동 가속/감속 부드럽게, 에코가 옆을 지날 때 소름 한 번.
- 금지: 기존 2D 코어 수정, 푸시, main 접근. 신규 파일로만.
- 게이트(G0 수준): typecheck+lint 통과, 새 sim 유닛 테스트 최소(틱 결정론·기록/재생 왕복·양자화 yaw 재현), 브라우저 수동 확인 가능 상태. 풀 게이트 재배선은 G4.
